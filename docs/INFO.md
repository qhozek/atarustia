# `.info`

Карточка повторяет четыре блока исходного Info-модуля: Owner; Codename/Branch/update;
Prefix/Uptime; CPU/RAM/Kernel/Host. Ссылки ведут на владельца и коммит atarustia в GitHub.
В английском и русском режиме используются исходные английские подписи, статус обновлений переведён.

Настройки: `.config atarustiaInfo`. Также доступны `.fconfig atarustiaInfo <key> <JSON>` и reset в меню.

| Ключ | По умолчанию | Назначение |
|---|---|---|
| custom_message | null | HTML-шаблон вместо стандартного текста |
| rich_mode | false | Rich HTML для Premium-аккаунта |
| banner_url | баннер проекта | HTTPS-картинка; пустая строка выключает |
| quote_media | true | Web-page preview вместо обычной фотографии |
| invert_media | true | Картинка над текстом |
| help_banner_url | баннер проекта | Картинка rich-справки; пустая строка выключает |

Шаблон: `{me}`, `{codename}`, `{prefix}`, `{upd}`, `{uptime}`, `{cpu_usage}`, `{ram_usage}`,
`{branch}`, `{commit}`, `{kernel}`, `{platform}`. Фигурные скобки — `{{` / `}}`.
Значения HTML-экранированы; me/commit/prefix/upd содержат готовое форматирование.
Python-выражения, format specs и placeholders внешних Python-модулей не исполняются.
Неизвестный placeholder отклоняется до сохранения настроек.

CPU — общая загрузка системы за короткий интервал. RAM — RSS процесса и доступных дочерних процессов, MiB.
Замер выполняется вне async event loop. Недоступная метрика отображается как «—», не как нулевое значение.
Upstream проверяется через штатный updater с таймаутом 5 секунд; ошибка сети не означает «актуальная версия».

Исходящие команды редактируются, входящие с выданными правами получают отдельный ответ.
В фото-режиме сначала отправляется карточка, затем удаляется исходящая команда.
Reply target сохраняется. Rich edit передаёт только rich_message, без конкурирующих text/entities/media.
Premium/custom-emoji отказ даёт обычный fallback; WEBPAGE_MEDIA_EMPTY убирает картинку.
Flood wait и ошибки соединения не превращаются в повторные отправки.

При недоступном inline/rich интерфейсе `.help` остаётся обычным текстом без баннера.
Офлайн-тесты проверяют карточку, entities, конфигурацию и native host metrics.
Отображение rich/preview на реальном аккаунте требует отдельной проверки в Telegram.
