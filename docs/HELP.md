# Справка

`.help` повторяет структуру исходного Info-модуля: баннер, логотип, badges с количеством модулей
и префиксом, секции встроенных/внешних модулей, счётчики команд и краткие описания.
Внешние модули идут по 15 на страницу; встроенные остаются на каждой странице.
Карточки и каталог имеют обычный HTML fallback с клавиатурой без rich-картинки.

- `.help <модуль>` — имя без учёта регистра.
- `.help <команда>` / `.help <префикс><команда>` — модуль команды; алиасы тоже разрешаются.
- Неточное имя — ближайший модуль с предупреждением.
- `.help -f` — скрытые модули; `.help -c` — встроенные; `.help -l` — внешние.
- Флаги разбираются как отдельные аргументы и не портят имена, содержащие `-f`.
- Именованная Rhai library показывает отдельное уведомление вместо карточки модуля.

Карточка содержит тип, описание, usage, команды с copy-кнопками и алиасами, inline/guest handlers,
metadata и настройки, если они доступны. В карточке Info перечислены placeholders `.info`.
Команды и handlers разбиваются на страницы по 8 элементов, чтобы обычный fallback укладывался в Telegram limits.
Короткий раздел команд раскрыт по умолчанию; длинный — свёрнут в rich UI.

Владелец может скрыть/вернуть модуль и открыть настройки с возвратом в исходную карточку.
«Скрытые модули» показывает список с кнопками возврата и «Вернуть все».
`.helphide` принимает встроенные, JSON/Rhai и native Rust модули. Команды скрытых модулей продолжают работать.

Текстовые команды фильтруются через тот же AccessCache и permissions, что dispatcher, inline — через inline security,
guest — по текущим owner-only правилам. При каждом переходе разрешения проверяются заново.
Не-владелец не получает прав через `-f` или старую кнопку. Скрытие и настройки доступны только владельцам.
Пакетные формы не могут вызвать core-help preferences/config actions.

JSON manifest допускает необязательные metadata:

```json
"help": {
  "version": "1.2.0",
  "developer": "Author",
  "banner_url": "https://example.com/module.png"
}
```

Metadata входит в одобряемый SHA-256 пакета. Нативный Rust SDK предоставляет
`Module::help_metadata()`. HTTPS URL проверяется, динамические тексты экранируются.
Пользовательские Python placeholders и библиотеки не исполняются.

Встроенные Rust-подсистемы сгруппированы в карточки, а не представлены вымышленными Python-экземплярами.
Синхронный `screens::help` предназначен для доверенного owner-кода; сетевые обработчики используют
`help::build` с явным caller и исходным message. Живое rich-отображение в Telegram ещё требует проверки.
